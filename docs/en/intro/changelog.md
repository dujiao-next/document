# Changelog

Release notes for every version are published on GitHub Releases. This site no longer keeps a copy, which avoids the page falling behind or drifting out of sync.

See: <https://github.com/dujiao-next/dujiao-next/releases>

Each release describes:

- New features and configuration options
- Breaking changes
- Database schema changes
- New configuration fields

For upgrade steps, see the [Upgrade Guide](/en/deploy/upgrade).
